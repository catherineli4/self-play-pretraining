# Plots

Generated by `scripts/plot_results.py` from the files in `results/` and the local run logs. SVG, one file per figure, grouped by experiment.

Axis labels carry ↓ when lower is better (bits per byte, tokens to a threshold) and ↑ when higher is better (accuracy, improvement over scratch). The training-dynamics panels are descriptive and carry neither.
